# 🧮 Workforce Scenario Engine

AI-powered workforce planning tool built by an HR leader for HR leaders.

## What It Does
- **Predictive Modeling:** 12-month Monte Carlo simulation of headcount, cost, and attrition
- **Tornado Sensitivity Analysis:** Instantly see which assumptions drive your outcomes
- **AI-Generated Insights:** Auto-flags flight risks, succession gaps, and cost pressures
- **Scenario Comparison:** Status Quo vs. Aggressive Growth vs. Cost Optimization

## Built With
- Python + Streamlit (frontend)
- Plotly (interactive charts)
- Pandas + NumPy (data & simulation)

```bash
pip install streamlit plotly pandas numpy
